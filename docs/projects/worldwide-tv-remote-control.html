Product overview

Worldwide TV: Remote Control — a mobile TV remote experience.

This project is part of Muhammad Usama’s portfolio and experience. It is presented as founder work, rather than a claim that SpheresX delivered it for a client.

Featured capabilities

  • WiFi Smart TV remote control
  • Keyboard, voice typing & smart keypad
  • Quick access to Netflix, Prime & YouTube
  • Real-time photo & video casting
  • Haptic feedback on remote buttons
  • Multiple remote themes & UI styles
  • Adapty subscriptions (Weekly, Monthly, Yearly)
  • Firebase, GameAnalytics & AdMob integration
