Product overview

CareHub is a scalable mobile healthcare app built for caregivers, patients, and family members, delivering essential real-time features and smooth cross-platform performance on Android and iOS.

This project is part of Muhammad Usama’s portfolio and experience. It is presented as founder work, rather than a claim that SpheresX delivered it for a client.

Featured capabilities

  • Role-based access for caregiver, patient, and family
  • Cross-platform Flutter app (iOS & Android)
  • Phone number authentication via Firebase
  • Real-time chat for connected care
  • Push notifications with FCM
  • Riverpod for scalable state management
  • Multilingual UI with Flutter Intl
  • Responsive and scalable design
